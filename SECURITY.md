# Security

Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/liquidlm/skills/security/advisories/new).
Do not open public issues for security reports. If the advisory channel is
unavailable, use `support@liquidlm.com` with "Security" in the subject.

Conventions and installers must never contain credentials, tokens or real user
URLs. Report any content that could trick an assistant into unsafe tool use as
a security issue, not a content bug.

Supported versions: fixes land on the latest alpha prerelease.
